Odgovori na pitanja za ponavljanje

Slide 21 odgovori

1. Što vam je sve potrebno za izradu mrežne stranice?

  Za izradu mrežne stranice, potrebno je imati alat za uređivanje teksta (VS Code, Notepad...), mjesto gdje su spremljeni podaci o web stranici (često na računalu poslužitelja), jezik u kojem se stranica dizajnira (HTML) te domena stranice.

2. Zašto vam je svejedno koji operativni sustav koristite pri izradi mrežne stranice?

  Za izradu mrežne stranice je svejedno koji se operativni sustav koristi jer su ta dva pojma nepovezana. Potrebna je programska podrška za izradu stranice te internet za prikaz. Sve mrežne stranice se pokreću u pregledniku.

3. Što je WWW kao pojam? Objasnite.

  WWW je World Wide Web. To je najpopularnija usluga koja omogućava pregledavanje mrežnih stranica i digitalnih informacija. Prvu WWW stranicu objavio je znanstvenik Tim Berners Lee u CERN-u.

4. Opišite što je mrežna stranica kao HTML dokument!

  Mrežna stranica kao HTML dokument je tekstualna datoteka koja sadrži posebne oznake i prate sintaksu. Te oznake govore pregledniku kako treba prikazati objekte na mrežnoj stranici.

5. Navedi neke mrežne standarde te opiši jedan (svrha, puni naziv i slično)!

  Mrežni standardi su tehnologije za izradu standardiziranih mrežnih stranica (HTML, CSS, DOM...)

  HTML (Hypertext markup language) je mrežni standard kojim označavamo elemente stranice. Današnji standart HTML-a je html:5

Slide 31 odgovori

1. Čemu služi i što mrežnom pregledniku govori deklaracija < !DOCTYPE html > koja se nalazi na samom početku dokumenta?

 Deklaracija < !DOCTYPE html > pregledniku daje informaciju o tome kakav dokument može očekivati. Kada upišemo < !DOCTYPE html >, preglednik zna da je riječ o .html dokumentu.

2. Koje tri važne informacije o dokumentu se nalaze unutar elementa < head >, a koje se uglavnom ne vide izravno na samoj web stranici?

  U < head > elementu nalaze se meta podaci (podaci o podacima) koji nisu prikazani na stranici. Meta podaci definiraju naslov dokumenta, stilove te kako da računalo sprema/učitava pojedine simbole (UTF-8).

3. Na kojem točno mjestu u mrežnom pregledniku se prikazuje naslov stranice koji smo zapisali unutar oznake < title >?

  Prikazuje se na kartici (tab-u), na vrhu našeg preglednika.

4. Što sve sadrži element < body > i koji se elmenti u njemu nalaze za korisnika?

  U elementu < body > se nalazi sav sadržaj HTML dokumenta, kao što su naslovi, tekst (paragraf), poveznice, slike, liste, tablice...

5. Koja je uloga mrežnog preglednika (poput Chromea ili Firefoxa) i zašto je važno da HTML dokument bude pravilno napisan bez pogrešaka u strukturi?

  Mrežni preglednik nam prikazuje mrežne stranice. Bitno je da HTML dokument bude pravilno napisan kako bi preglednik mogao točno učitati mrežnu stranicu. U slučaju da HTML dokument nije pravilno strukturiran, preglednik ne bi mogao ispravno prikazati stranicu.

6. Što predstavlja oznaka https:// na početku adrese i po čemu se ona razlikuje (zašto je sigurnija) od starije oznake http://?

  Oznaka https:// znači Hypertext Transfer Protocol Secure. Običan http:// omogućuje pregledniku i web serverima da komuniciraju, no netko tko je na toj mreži bi mogao ukrasti razmijenjene podatke. Noviji https:// štiti naše podatke tako što ih čini nečitljivim.

7. U primjeru adrese https://www.example.com, detaljno objasni što označava https://, što oznalčava www., a što predstavlja example.com?

  U adresi https://www.example.com, https:// predstavlja ranije objašnjeni protokol, www. je takozvana subdomena koja nas upućuje prema lokaciji računala koji je domaćin web stranice. Example.com je glavna adresa stranice.

8. Zašto se u web dizajnu početna stranica nekog mrežnog sjedišta standardno mora nazvati točno index.html? Što bi se dogodilo da je nazovemo drukčije?

  Web serveri su programirani da traže datoteku koja je nazvana točno index.html. Kada korisnik zatraži pristup domeni bez da odredi točnu stranicu, server se pozove na index.html datoteku. U slučaju da početna stranica nije nazvana index.html, server će prikazati error 403.

9. Zašto se HTML datoteke moraju spremati isključivo s ekstenzijom .html i kako preglednik reagira kad prepozna tu eksetenziju?

  Preglednik prepoznaje .html ekstenziju kao web stranicu. Kada ju prepozna, on se prilagodi sintaksi HTML dokumenta i ne prikazuje oznake kao < p >.

10. Zašto se u HTML5 standardu koriste semantički elementi (poput < header >, < nav >, < footer >) i po čemu se razlikuju od općih spremnika bez značenja kao što su < div > i < span >?

  U HTML 5, semantički elementi se kroiste kao bi opisali što određeni dio stranice predstavlja. (npr. < header > je zaglavlje), dok < div > i < span > samo grupiraju sadržaj.
